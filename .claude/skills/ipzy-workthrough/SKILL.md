# IPZY Workthrough

작업 완료 후 간결한 한국어 요약 문서를 자동 생성합니다.

## 필수 실행 사항

이 스킬이 호출되면 **반드시 다음을 실행**합니다:

1. 현재 작업 내용 분석 (대화 컨텍스트에서)
2. `docs/workthrough/` 폴더가 없으면 생성 (Bash: `mkdir -p`)
3. `docs/workthrough/YYYYMMDD_{작업명}.md` 파일 **실제 생성** (Write 도구 사용)
4. `docs/workthrough/README.md` 인덱스 **실제 갱신** (Write 도구 사용)

**중요: 템플릿만 보여주지 말고, 실제 파일을 생성하세요!**

## 핵심 원칙

1. **간결함**: 2-3문장 요약, 불필요한 설명 제외
2. **핵심만**: 무엇을 했는지, 왜 했는지
3. **실용적**: 다음 단계 명확히 제시
4. **코드는 최소한**: 핵심 코드만 포함

## 워크플로우

```
작업 완료
       ↓
[1단계] 작업 내용 분석
       ↓
[2단계] 폴더 확인/생성 - Bash 실행
       ↓
[3단계] 문서 생성 - Write 도구로 파일 생성
       ↓
[4단계] 인덱스 갱신 - Write 도구로 README.md 갱신
       ↓
docs/workthrough/YYYYMMDD_{작업명}.md 생성 완료
```

## 작성 가이드

### 개요 작성법

**좋은 예:**
```
AI 추천 API에 Swagger 문서화를 적용했습니다.
프론트엔드 팀이 API 명세를 쉽게 확인할 수 있습니다.
```

**나쁜 예:**
```
이번 작업에서는 RecommendationController 클래스에 있는
recommend 메서드와 getHistory 메서드에 @Operation 어노테이션과
@ApiResponses 어노테이션을 추가하여 Swagger UI에서 API 문서가
자동으로 생성되도록 하는 작업을 수행하였습니다...
(너무 길고 장황함)
```

### 변경 사항 작성법

**좋은 예:**
```
- RecommendationController에 @Operation 추가
- Request/Response DTO에 @Schema 추가
- 에러 응답 코드 문서화 (401, 403, 500)
```

**나쁜 예:**
```
- src/main/java/com/ipzy/domain/recommendation/controller/RecommendationController.java 파일을 수정하였음
(경로가 너무 길고 불필요)
```

### 핵심 코드 작성법

**포함할 것:**
- 새로 추가된 핵심 로직
- 중요한 패턴이나 구조
- 다른 개발자가 알아야 할 부분

**제외할 것:**
- import 문
- getter/setter
- 단순 반복 코드
- 전체 클래스 코드

### 다음 단계 작성법

**좋은 예:**
```
- [ ] ProductController 동일 적용
- [ ] 공통 에러 응답 스키마 정의
```

**나쁜 예:**
```
- [ ] 나중에 더 개선하기
(너무 모호함)
```

## 사용 예시

### 입력
```
"방금 작업 정리해줘"
"workthrough 만들어줘"
```

### 출력

```markdown
# RecommendationController Swagger 문서화

> 작성일: 2025-12-15 14:30
> 도메인: recommendation
> 작업 유형: 문서화

## 개요

AI 추천 API에 Swagger 어노테이션을 추가하여 API 문서를 자동 생성하도록 했습니다.
Swagger UI에서 API 테스트와 명세 확인이 가능합니다.

## 변경 사항

- RecommendationController에 @Tag, @Operation 추가
- RecommendationRequest/Response에 @Schema 추가
- 에러 응답 코드 문서화 (401, 403, 500)

## 핵심 코드

```java
@Tag(name = "Recommendation", description = "AI 스타일 추천 API")
@Operation(summary = "AI 스타일 추천", description = "사용자 선호도 기반 코디 추천")
@ApiResponses({
    @ApiResponse(responseCode = "200", description = "추천 성공"),
    @ApiResponse(responseCode = "401", description = "인증 필요")
})
```

## 결과

- Swagger UI: http://localhost:8080/swagger-ui.html
- API 문서 자동 생성 확인
- 테스트 전체 통과
