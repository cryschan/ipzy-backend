# 세션 만료 메시지 개선 계획

**작업**: 로그인 후 세션 유효시간이 만료된 후 사용자에게 친화적인 메시지 제공
**현재 상태**: `"세션이 만료되었습니다"` (AUTH_005)

---

## 1. 작업 분석 및 이해

### 요구사항 분석
- **핵심 목표**: 세션 만료 시 사용자에게 친화적인 메시지 전달
- **왜 필요한가**: 현재 "세션이 만료되었습니다"는 기술적이고 차가운 느낌
- **성공 기준**: 사용자가 상황을 쉽게 이해하고, 다음 행동(재로그인)을 자연스럽게 유도

### 현재 상태 파악
```java
// AuthErrorCode.java:19
SESSION_EXPIRED(HttpStatus.UNAUTHORIZED, "AUTH_005", "세션이 만료되었습니다")
```

**영향 범위**:
- `SecurityConfig.java:132` - authenticationEntryPoint에서 사용
- `AuthException.java:39` - sessionExpired() 팩토리 메서드
- `AuthControllerTest.java:103` - 테스트 검증

---

## 2. 접근 방식 및 트레이드 오프 분석

### 접근 방식 A: 단순 메시지 변경
**설명**: AuthErrorCode의 메시지만 변경

```java
SESSION_EXPIRED(HttpStatus.UNAUTHORIZED, "AUTH_005",
    "오랜 시간 활동이 없어 자동으로 로그아웃되었어요. 다시 로그인해주세요.")
```

**장점**:
- 변경 범위 최소 (1줄)
- 즉시 적용 가능
- 기존 코드 구조 유지

**단점**:
- 모든 클라이언트에 동일 메시지
- 상세 정보(만료 시간 등) 제공 불가

**위험도**: Low

---

### 접근 방식 B: 에러 코드 분리 + 상세 메시지
**설명**: 세션 만료 원인별로 에러 코드 분리

```java
SESSION_EXPIRED_TIMEOUT(HttpStatus.UNAUTHORIZED, "AUTH_005",
    "오랜 시간 활동이 없어 자동으로 로그아웃되었어요."),
SESSION_EXPIRED_DUPLICATE(HttpStatus.UNAUTHORIZED, "AUTH_009",
    "다른 기기에서 로그인하여 현재 세션이 종료되었어요.")
```

**장점**:
- 원인별 맞춤 메시지 가능
- 사용자 경험 세분화

**단점**:
- 구현 복잡도 증가 (세션 만료 원인 추적 필요)
- Spring Security의 세션 이벤트 리스너 추가 필요
- 테스트 케이스 증가

**위험도**: Medium

---

### 접근 방식 C: 프론트엔드 위임
**설명**: 백엔드는 코드만 전달, 프론트엔드에서 사용자 친화적 메시지 표시

```java
// 백엔드: 기존 유지
SESSION_EXPIRED(HttpStatus.UNAUTHORIZED, "AUTH_005", "Session expired")

// 프론트엔드: 코드 기반 메시지 매핑
AUTH_005 → "오랜 시간 활동이 없어 자동으로 로그아웃되었어요."
```

**장점**:
- 다국어 지원 용이
- 프론트엔드에서 UI 맥락에 맞게 표시 가능
- 백엔드 변경 없음

**단점**:
- 프론트엔드 작업 필요
- 백엔드-프론트엔드 메시지 동기화 필요

**위험도**: Low

---

### 🎯 권장 접근 방식: A

**선택 이유**:
1. 현재 단일 언어(한국어) 서비스
2. 프론트엔드 작업 없이 즉시 개선 가능
3. 향후 B나 C로 확장 가능한 구조

**트레이드 오프 요약**:
- 포기하는 것: 세션 만료 원인별 상세 메시지
- 얻는 것: 빠른 구현, 낮은 위험도

---

## 3. 상세 구현 계획

### 3.1 영향받는 파일

| 파일 | 변경 내용 |
|------|-----------|
| `AuthErrorCode.java:19` | 메시지 변경 |
| `AuthControllerTest.java:103` | 테스트 기대값 수정 |

### 3.2 변경 내용

**Before**:
```java
SESSION_EXPIRED(HttpStatus.UNAUTHORIZED, "AUTH_005", "세션이 만료되었습니다")
```

**After** (제안):
```java
SESSION_EXPIRED(HttpStatus.UNAUTHORIZED, "AUTH_005",
    "오랜 시간 활동이 없어 자동으로 로그아웃되었어요. 다시 로그인해주세요.")
```

**대안 메시지**:
1. `"로그인 세션이 종료되었어요. 다시 로그인해주세요."` (간결)
2. `"안전을 위해 자동 로그아웃되었어요. 다시 로그인해주세요."` (보안 강조)
3. `"오랜 시간 활동이 없어 자동으로 로그아웃되었어요."` (원인 설명)

### 3.3 단계별 작업 순서

1. **1단계**: 메시지 결정
   - 사용자에게 메시지 선택지 확인

2. **2단계**: AuthErrorCode 수정
   - `SESSION_EXPIRED` 메시지 변경

3. **3단계**: 테스트 수정
   - `AuthControllerTest` 기대값 수정

4. **4단계**: 빌드 및 검증
   - `./gradlew clean test` 실행
