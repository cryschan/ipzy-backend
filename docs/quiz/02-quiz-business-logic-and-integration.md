## 주요 비즈니스 로직

### 세션 시작

**플로우:**

1. 활성화된 퀴즈 조회 (`isActive = true`)
2. 사용자 조회 (로그인한 경우, 없어도 가능)
3. 세션 생성 (비로그인 시 `user = null`)

**특징:**

- 비로그인 사용자도 세션 생성 가능
- 익명 세션은 나중에 사용자에게 연결 가능

### 답변 저장/수정

**플로우:**

1. 세션 조회 및 완료 여부 검증
2. 질문 조회 및 세션 소속 검증
3. 옵션 유효성 검증
4. 기존 답변 있으면 업데이트, 없으면 생성

**검증 사항:**

- 완료된 세션은 답변 수정 불가
- 질문이 세션의 퀴즈에 속하는지 확인
- 옵션 유효성 및 질문 타입별 선택 개수 검증
- 중복 옵션/답변 방지

### 세션 완료

**플로우:**

1. 세션 조회 (답변 포함)
2. 질문 목록 조회 (옵션 포함)
3. 답변 검증:
   - 필수 질문 답변 여부
   - 답변 유효성 (옵션, 타입별 검증)
   - 중복 답변 체크
4. 세션 완료 처리 (`completed = true`)

**검증 사항:**

- 모든 필수 질문에 답변했는지 확인
- 각 답변이 유효한지 확인
- 같은 질문에 중복 답변이 없는지 확인

### 옵션 검증

**검증 항목:**

1. 선택한 옵션이 null이거나 비어있지 않은지
2. 질문에 옵션이 있는지
3. 중복 옵션 선택 방지
4. 각 옵션이 유효한 값인지 (공백 검증 포함)
5. 질문 타입별 선택 개수:
   - `SINGLE`: 정확히 1개
   - `MULTIPLE`: 1개 이상

**에러 코드:**

- `QUIZ_002`: 유효하지 않은 퀴즈 응답
- `QUIZ_009`: 유효하지 않은 옵션
- `QUIZ_010`: 단일 선택 질문에는 1개만 선택 가능

## 추천 도메인 연동

### 연동 흐름

```
[퀴즈 완료] → QuizSession.completed = true
  ↓
[추천 생성 요청] → RecommendationService.generateRecommendation()
  ↓
[답변 데이터 변환] → QuizAnswerDto 변환
  ↓
[Python AI 서비스] → RecommendationRequest 전송
  ↓
[AI 추천 결과] → Recommendation 저장
```

### 주요 연동 포인트

#### 1. 세션 완료 후 추천 생성

- **조건**: 완료된 세션(`completed = true`)만 가능
- **중복 방지**: 같은 세션으로 여러 번 추천 생성 불가 (재생성 API 별도)
- **사용자 인증**: 추천 생성 시점에는 로그인 필수

#### 2. 익명 세션 연결

**시나리오:**

- 비로그인 상태에서 퀴즈 완료 → 로그인 후 추천 생성 요청
- 추천 생성 시점에 `session.assignUser()`로 자동 연결
- 이미 사용자가 연결된 세션은 재연결 불가 (`QUIZ_017`)

#### 3. 데이터 변환

- `QuizAnswer` → `QuizAnswerDto` 변환
- 세션 ID와 답변 목록을 Python AI 서비스로 전송
