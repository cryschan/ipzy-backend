## QuizSession 상태 전이

### 상태

QuizSession은 두 가지 상태를 가집니다:

- **진행 중** (`completed = false`): 세션이 생성되고 답변을 받는 상태
- **완료** (`completed = true`): 모든 필수 질문에 답변하고 완료 처리된 상태

### 상태 전이 흐름

```
[생성] → 진행 중 (completed = false)
  ↓
[답변 저장/수정] → 진행 중 유지
  ↓
[완료 처리] → 완료 (completed = true)
  ↓
[완료 후] → 변경 불가 (영구적)
```

### 상태별 동작

#### 1. 생성 (진행 중)

- 활성화된 퀴즈만 세션 생성 가능
- 로그인 여부와 무관하게 생성 가능
- 초기 상태: `completed = false`, `answers = []`

#### 2. 진행 중

- 답변 저장/수정, 진행 상태 조회, 질문 조회 가능
- 같은 질문에 대한 중복 답변 불가
- 옵션 유효성 검증 필수

#### 3. 완료

- 모든 필수 질문에 답변 완료 후 완료 처리
- `session.complete()` 호출 → `completed = true`

#### 4. 완료 후

- 답변 저장/수정 불가 (영구적)
- 진행 상태 조회 및 추천 생성 요청 가능

## 세션 수명 정책

### 문제 상황

**무한히 쌓이는 미사용 세션:**

- 비로그인 사용자가 세션을 생성하고 이탈
- 로그인 사용자가 세션을 생성하고 미완료 상태로 방치
- 완료된 세션도 영구 보관되어 DB 용량 증가

**영향:**

- DB 용량 증가
- 불필요한 데이터 조회 성능 저하
- 데이터 정리 작업 필요

### 정리 정책 (계획)

**대상:**

- 생성된 지 N분(예: 30분) 이상 지난 미완료 세션
- 완료된 지 오래된 세션 (선택적)

**처리 방식:**

- 스케줄러 배치 처리 활용
- 매일 새벽 4시에 일괄 삭제
- CASCADE 설정으로 세션 삭제 시 답변도 자동 삭제

**주의사항:**

- 완료된 세션은 추천 생성에 사용되므로 보존 기간 고려 필요
- 사용자가 진행 중인 세션은 삭제하지 않도록 충분한 시간 여유 필요

## 비회원 처리 정책

### 접근 정책

**모든 퀴즈 API는 비회원 접근 가능:**

- 퀴즈 세션 시작
- 질문 조회
- 답변 저장/수정
- 세션 완료
- 진행 상태 조회

**인증:**

- `@AuthenticationPrincipal`은 nullable 처리
- `userId`가 null이면 익명 세션으로 생성

### 익명 세션 처리

- 비로그인 시 `user = null`로 저장
- `isAnonymous()` 메서드로 익명 여부 확인
- 추천 생성 시점에 `session.assignUser()`로 자동 연결
- 이미 사용자가 연결된 세션은 재연결 불가

## 중복 세션 허용 정책

### 정책

**같은 사용자가 같은 퀴즈에 대해 여러 세션 생성 허용**

### 허용 이유

#### 1. 복잡성 회피

**막으면 생기는 문제:**

- 기존 세션 조회 로직 필요
- 세션 상태 확인 및 복잡한 분기 처리
- 사용자가 이전 세션을 이어서 진행할지, 새로 시작할지 선택 UI 필요

**허용 시:**

- 단순히 새 세션 생성
- 복잡한 로직 불필요

#### 2. 자연스러운 사용자 경험

**퀴즈 특성:**

- 퀴즈는 이어서 진행하는 기능이 없음
- 사용자가 다시 시작하고 싶을 때 새로 시작하는 것이 자연스러움

**시나리오:**

- 사용자가 퀴즈를 풀다가 중단
- 나중에 다시 시작하고 싶을 때
- 기존 세션을 찾아서 이어서 풀기보다는 새로 시작하는 것이 직관적

#### 3. 세션 충돌 방지

**막으면 생기는 문제:**

- 기존 세션을 찾아서 재사용하는 과정에서 세션 상태가 꼬일 수 있음
- 완료된 세션과 진행 중인 세션 구분 필요
- 사용자가 의도하지 않은 세션을 사용할 위험

**허용 시:**

- 매번 새로운 세션으로 시작
- 세션 상태가 명확하고 충돌 없음

### 구현

**현재 구현:**

- 세션 생성 시 기존 세션 확인 없음
- 단순히 새 세션 생성 및 저장

**결과:**

- 사용자는 언제든지 새로 시작 가능
- 각 세션은 독립적으로 관리
- 완료된 세션은 추천 생성에 사용 가능
