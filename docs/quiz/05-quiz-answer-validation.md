## QuizAnswer 저장 전략

### 저장 방식

**Upsert 패턴:**

- 같은 질문에 대한 답변이 있으면 업데이트, 없으면 새로 생성
- 세션당 질문당 하나의 답변만 존재

### 데이터 저장 형식

**selectedOptions (JSONB):**

- PostgreSQL의 JSONB 타입 사용
- `List<String>` 형태로 저장
- 옵션 값(`QuizOption.value`)만 저장

**특징:**

- 옵션 표시 텍스트(`text`)가 아닌 값(`value`) 저장
- JSON 배열로 여러 옵션 저장 가능
- 질문 타입에 따라 1개 또는 여러 개 저장

### 옵션 값 저장

**QuizOption.value 사용:**

- 답변에는 `QuizOption.value` 값만 저장
- `QuizOption.text`는 표시용으로만 사용
- `value`와 `text`는 다를 수 있음 (예: `value="clean"`, `text="깔끔한 스타일"`)

**이유:**

- 값 변경 시 일관성 유지
- 표시 텍스트 변경 시 답변 데이터 영향 없음
- AI 추천 시스템에서 값 기반 처리 용이

## 도메인 무결성 검증 규칙

### 검증 계층

```
1. 세션 검증
   ↓
2. 질문 소속 검증
   ↓
3. 옵션 유효성 검증
   ↓
4. 질문 타입별 검증
   ↓
5. 중복 방지 검증
```

### 1. 세션 검증

**검증 항목:**

- 세션 존재 여부 (`QUIZ_003`)
- 세션 완료 여부 (`QUIZ_004`)

**규칙:**

- 완료된 세션은 답변 저장/수정 불가
- 세션이 존재하지 않으면 답변 저장 불가

### 2. 질문 소속 검증

**검증 항목:**

- 질문 존재 여부 (`QUIZ_007`)
- 질문이 세션의 퀴즈에 속하는지 (`QUIZ_008`)

**규칙:**

- 다른 퀴즈의 질문에 답변 불가
- 세션의 퀴즈에 속한 질문만 답변 가능

### 3. 옵션 유효성 검증

**검증 항목:**

#### 3.1 기본 검증

- 선택한 옵션이 null이거나 비어있지 않은지 (`QUIZ_002`)
- 질문에 옵션이 있는지 (`QUIZ_002`)

#### 3.2 중복 옵션 방지

- 같은 옵션을 여러 번 선택 불가 (`QUIZ_002`)

#### 3.3 옵션 값 검증

- null 옵션 불가, 공백만 있는 옵션 불가 (`QUIZ_009`)
- 질문의 유효한 옵션 값인지 확인 (`QUIZ_009`)

### 4. 질문 타입별 검증

**SINGLE (단일 선택):**

- 정확히 1개만 선택해야 함 (`QUIZ_010`)

**MULTIPLE (다중 선택):**

- 최소 1개 이상 선택해야 함 (`QUIZ_002`)

### 5. 중복 방지 검증

**답변 중복 방지:**

- 같은 질문에 대한 답변은 하나만 존재
- Upsert 패턴으로 자동 처리

**옵션 중복 방지:**

- 같은 옵션을 여러 번 선택 불가
- `distinct()` 검증으로 처리

**세션 완료 시 중복 답변 체크:**

- 같은 질문에 여러 답변이 있는지 확인 (`QUIZ_002`)

### 6. 필수 질문 검증

**세션 완료 시 검증:**

- 모든 필수 질문(`required = true`)에 답변했는지 확인 (`QUIZ_005`)

**규칙:**

- 필수 질문은 반드시 답변해야 함
- 선택 질문은 답변하지 않아도 됨
- 완료 처리 시에만 검증 (저장 시에는 검증하지 않음)

## 검증 순서

### 답변 저장 시

1. 세션 존재 및 완료 여부 검증
2. 질문 존재 및 소속 검증
3. 옵션 유효성 검증 (기본, 중복, 값)
4. 질문 타입별 선택 개수 검증
5. Upsert 처리 (중복 답변 자동 방지)

### 세션 완료 시

1. 세션 존재 및 완료 여부 검증
2. 필수 질문 답변 여부 검증
3. 각 답변 유효성 검증 (옵션, 타입별)
4. 중복 답변 체크
5. 완료 처리

## 에러 코드

| 에러 코드  | HTTP | 설명                                               |
| ---------- | ---- | -------------------------------------------------- |
| `QUIZ_002` | 400  | 유효하지 않은 퀴즈 응답입니다                      |
| `QUIZ_003` | 404  | 퀴즈 세션을 찾을 수 없습니다                       |
| `QUIZ_004` | 400  | 이미 완료된 퀴즈 세션입니다                        |
| `QUIZ_005` | 400  | 필수 질문에 답변하지 않았습니다                    |
| `QUIZ_007` | 404  | 퀴즈 질문을 찾을 수 없습니다                       |
| `QUIZ_008` | 400  | 해당 질문이 세션의 퀴즈에 속하지 않습니다          |
| `QUIZ_009` | 400  | 유효하지 않은 옵션입니다                           |
| `QUIZ_010` | 400  | 단일 선택 질문에는 1개의 옵션만 선택할 수 있습니다 |

## 참고 사항

- `selectedOptions`는 `QuizOption.value`와 일치해야 함
- 세션 삭제 시 답변은 CASCADE로 자동 삭제
- 새로운 질문 타입 추가 시 `validateOptions()` 메서드 수정 필요
