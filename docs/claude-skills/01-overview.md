# Skills 개요

## Skills란?

**Agent Skills**는 Claude의 기능을 확장하기 위한 **모듈화된 능력(capability)**입니다.

마크다운 기반 지침서로 Claude의 행동을 정의하며, 사용자가 명시적으로 호출하지 않아도 **Claude가 자동으로 필요 시점에 사용**합니다.

## 핵심 특징

| 특징 | 설명 |
|------|------|
| **모델 호출** | 사용자가 명시적으로 호출하지 않아도 Claude가 자동으로 선택 |
| **슬래시 커맨드와의 차이** | `/command` 같은 명시적 호출이 아니라 자동 발견 방식 |
| **팀 공유 가능** | Git 리포지토리에 커밋해 팀원과 공유 |

## 용도

- 반복적인 작업 자동화
- 팀 워크플로우 표준화
- 프로젝트 특화 전문성 패키징
- 컨텍스트 크기 최적화

## 저장 위치

### 개인 Skills (Personal Skills)

```
~/.claude/skills/스킬명/
├── SKILL.md (필수)
├── reference.md (선택)
└── examples.md (선택)
```

**특징**: 모든 프로젝트에서 사용 가능, 개인 워크플로우용

### 프로젝트 Skills (Project Skills)

```
.claude/skills/스킬명/
├── SKILL.md (필수)
├── reference.md (선택)
└── templates/ (선택)
```

**특징**: Git 리포지토리에 커밋, 팀원과 자동 공유

## 개인 vs 프로젝트 스킬 비교

| 항목 | 개인 Skills | 프로젝트 Skills |
|------|-----------|----------------|
| **저장 위치** | `~/.claude/skills/` | `.claude/skills/` |
| **공유 범위** | 현재 사용자만 | 팀원 (Git 공유) |
| **사용 프로젝트** | 모든 프로젝트 | 특정 프로젝트만 |
| **버전 관리** | 로컬만 | Git 리포지토리 |
| **사용 시기** | 개인 선호, 실험 | 팀 표준, 프로젝트 특화 |

## 선택 가이드

### 개인 Skills로 만들기

- 개인 코딩 스타일 선호
- 실험 중인 아이디어
- 여러 프로젝트에서 사용할 기술
- 개인 생산성 도구

### 프로젝트 Skills로 만들기

- 팀 코딩 컨벤션
- 프로젝트 특화 워크플로우
- 공유 템플릿 또는 스크립트
- 팀원이 배워야 할 도메인 지식
