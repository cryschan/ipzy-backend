# MVP 범위 정의

## MVP 목표

> 사용자가 퀴즈를 풀고 AI 추천 코디를 받아 저장하거나 구매 링크로 이동할 수 있다.

## 포함 기능

### 핵심 (Must Have)

| 기능 | 설명 | 우선순위 |
|------|------|---------|
| 스타일 퀴즈 | 질문/옵션 표시, 답변 제출 | P0 |
| AI 추천 | 퀴즈 결과 기반 코디 추천 생성 | P0 |
| 추천 조회 | 추천된 코디 및 상품 상세 보기 | P0 |
| 상품 상세 | 가격, 이미지, 구매 링크 | P0 |

### 부가 (Should Have)

| 기능 | 설명 | 우선순위 |
|------|------|---------|
| 회원가입/로그인 | OAuth2 카카오 인증 | P1 |
| 코디 저장 | 마음에 드는 추천 저장 | P1 |
| 저장된 코디 조회 | 내가 저장한 코디 목록 | P1 |

## 제외 기능 (MVP 이후)

| 기능 | 제외 이유 | 예상 시기 |
|------|----------|----------|
| 구독/결제 | MVP 검증 후 도입 | Phase 2 |
| 관리자 페이지 | 초기엔 직접 DB 관리 | Phase 2 |
| 네이버/구글 OAuth2 | 카카오로 시작, 점진적 추가 | Phase 2 |
| ActivityLog 수집 | MVP 검증 후 분석 필요 시 | Phase 2 |
| 다양한 퀴즈 | 하나의 퀴즈로 시작 | Phase 2 |
| 상품 검색/필터 | 추천 기반으로 시작 | Phase 2 |
| 비회원 추천 저장 | 로그인 필요로 단순화 | Phase 2 |

## 성공 기준

### 기능적 기준

- [ ] 회원이 퀴즈를 완료하고 추천을 받을 수 있다
- [ ] 추천된 코디를 저장할 수 있다
- [ ] 저장된 코디 목록을 조회할 수 있다
- [ ] 상품 구매 링크로 이동할 수 있다

### 기술적 기준

- [ ] API 응답 시간 < 3초 (AI 추천 제외)
- [ ] AI 추천 생성 < 10초
- [ ] 에러 발생 시 적절한 에러 메시지 반환

## 사용자 플로우

```
[비회원]
    │
    ▼
┌─────────────┐
│ 퀴즈 조회    │ (비회원도 가능)
└─────────────┘
    │
    ▼
┌─────────────┐
│ 퀴즈 시작    │ → 로그인 필요
└─────────────┘
    │
    ▼
┌─────────────┐
│ 회원가입     │
└─────────────┘
    │
    ▼
[회원]
    │
    ▼
┌─────────────┐
│ 퀴즈 시작    │
└─────────────┘
    │
    ▼
┌─────────────┐
│ 질문 답변    │ × N개
└─────────────┘
    │
    ▼
┌─────────────┐
│ 퀴즈 완료    │
└─────────────┘
    │
    ▼
┌─────────────┐
│ AI 추천 생성 │ ← Spring AI
└─────────────┘
    │
    ▼
┌─────────────┐
│ 추천 결과    │ → 상품 상세 보기
└─────────────┘     → 구매 링크 클릭
    │
    ├── [저장하기] → 코디 저장
    │
    └── [다시 하기] → 퀴즈 재시작
```
