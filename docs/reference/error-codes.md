## 에러 코드 네이밍 규칙

- **접두사**: 도메인 약어 (AUTH, USER, PROD, REC, OUTFIT, QUIZ, SUBSCRIPTION)
- **번호 체계**: `{도메인}_{3자리 숫자}` 또는 `{도메인}{3자리 숫자}`
- **소스 코드**: `src/main/java/com/ipzy/domain/{도메인}/exception/{Domain}ErrorCode.java`
